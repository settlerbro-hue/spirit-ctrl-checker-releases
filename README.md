# SPIRIT/CTRL Checker

Official Windows installers and automatic updates for SPIRIT/CTRL Checker.

[Download the latest version](https://github.com/settlerbro-hue/spirit-ctrl-checker-releases/releases/latest)

Version 1.6.0 adds sign-in through the league website and report delivery for moderator review. The player confirms report transfer before starting a check. Reports remain in an encrypted queue while delivery is pending, and a local HTML copy is saved on the PC.

Source code is maintained in a separate private repository.
